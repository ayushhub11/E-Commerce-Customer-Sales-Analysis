# E-Commerce Customer & Sales Performance Analysis

## Project Overview

This project focuses on analyzing e-commerce sales data to understand sales performance, customer behavior, product performance, and business trends.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Excel

## Dataset

Online Retail II Dataset from UCI Machine Learning Repository.

## Project Objectives

- Analyze overall sales and revenue.
- Identify top-performing products.
- Analyze customer purchasing behavior.
- Perform RFM customer segmentation.
- Analyze country-wise sales.
- Identify monthly, daily, and hourly sales trends.

## Key Business Insights

- Total Revenue: 10,271,762.66
- Total Orders: 20,951
- Total Customers: 4,312
- Unique Products: 4,534
- Best Sales Month: November 2010
- Highest Revenue Country: United Kingdom
- Peak Sales Day: Thursday
- Peak Sales Hour: 12 PM
- Best Selling Product: WHITE HANGING HEART T-LIGHT HOLDER

## Customer Segmentation

Customers were divided into five groups:

- Champions
- Loyal Customers
- Recent Customers
- At Risk
- Regular Customers

## Project Files

- Dataset: Original retail dataset
- Analysis: Python analysis scripts and cleaned data
- Notebooks: Data loading script
- Reports: Excel analysis report
- Visualizations: Sales and customer analysis charts

## How to Run the Project

1. Clone or download this repository.
2. Install the required libraries:

   pip install pandas numpy matplotlib seaborn openpyxl

3. Run the data loading script:

   python Notebooks/01_data_loading.py

4. Run the analysis scripts from the Analysis folder.
